# Meesho E-commerce Data Cleaning Project

## Project Overview
This project focuses on cleaning and validating a Meesho-style e-commerce practice dataset using Microsoft Excel and Power Query.

## Project Objectives
- Identify missing values.
- Check duplicate records.
- Verify data types.
- Standardize inconsistent values.
- Validate sales and profit calculations.

## Tools Used
- Microsoft Excel
- Power Query
- GitHub

## Data Cleaning Steps
- Checked missing values and duplicate records.
- Reviewed column data types.
- Standardized text values.
- Validated sales, cost, profit, and date fields.
- Documented data quality issues.

## Dataset
This project uses a practice e-commerce dataset and is not official Meesho company data.

## Project Status
Data cleaning and validation are being documented as part of this project.
